## Assignment 1.2 — Personal Profile

A personal website built with HTML and CSS.

- Name, photo and navigation links
- Personal introduction and a separate About page
- Skills list
- Contact form with name, email and message fields
- Google Fonts and a responsive layout

The contact form demonstrates the interface and browser validation.
It does not send emails.

Open index.html in a browser to view this assignment.

## Assignment 1.3 — Interactive Web Page

A web page built with HTML, CSS and JavaScript.

- Click Me changes the heading text and colour.
- Reset restores the original heading and colour.
- Button clicks are handled using addEventListener.

Open mypage.html in a browser to view this assignment.
